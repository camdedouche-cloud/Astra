# ASTRA — Le réveil du huitième sceau

RPG d'action dark fantasy en pixel art, jouable directement dans le navigateur (PC et mobile).

**Contenu de la démo :** prologue « Le réveil » + Chapitre 1 « Le village oublié », 6 classes, combats en temps réel, inventaire, coffres, boss.

## Jouer
Ouvre `index.html` dans un navigateur, ou utilise la version GitHub Pages du dépôt.

## Commandes
- PC : ZQSD/WASD pour bouger · J ou clic pour attaquer · Espace pour esquiver · K pour la compétence · R pour une potion · E pour parler · I pour l'inventaire
- Mobile : joystick à gauche, boutons à droite, touche un PNJ pour lui parler
